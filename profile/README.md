# HAIHQ

**Open Systems Lab**

HAIHQ is an Open Systems Lab building software for connected healthcare. We focus on open standards that help health systems exchange information and give developers a clear foundation for building interoperable tools.

## Our work

Our first project here is [haifhir](https://github.com/hai-hq/haifhir), a home for HAIHQ's work with FHIR (Fast Healthcare Interoperability Resources). FHIR defines a common way for healthcare systems to represent and exchange health information.

This organization brings our project code and documentation together.

## How we work

- Build around open standards and clear interfaces.
- Make integrations easier to understand and maintain.
- Share practical tools and documentation.
